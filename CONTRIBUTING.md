# Contribuindo para o projeto

Obrigado por considerar contribuir para este projeto! 🎉

## Como contribuir
- Faça um **fork** do repositório.
- Crie uma **branch** para sua alteração (`git checkout -b minha-alteracao`).
- Faça suas alterações e **commite** (`git commit -m "Descrição da alteração"`).
- Envie sua alteração para o GitHub (`git push origin minha-alteracao`).
- Abra um **Pull Request** e aguarde a revisão.

## Relatar problemas
Se encontrar um bug ou tiver sugestões, abra uma **issue** no repositório.

## Código de Conduta
Todos os colaboradores devem seguir o [Código de Conduta](CODE_OF_CONDUCT.md).

Depois de adicionar esse conteúdo, clique em **Commit changes** para salvar. Agora seu repositório terá um `CONTRIBUTING.md` válido! 🚀😃
